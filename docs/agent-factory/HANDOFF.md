# Development handoff

Review [Charlie PR #46](https://github.com/mrgarmise/charlie/pull/46) and [Dog PR #5](https://github.com/mrgarmise/dog/pull/5) together. The Dog draft depends on Dog PR #3. Charlie’s optional simulation demonstration also uses the pinned Charlie visual checkout listed in [the report](REPORT.md). Charlie's original standing-baseline and synthetic offset goal remain usable through the same CLI.

Keep the drafts in development. The next engineering dependency is a scheduler-owned generic lease boundary capable of terminating isolated sandbox tasks. The current sandbox lease fences result writes. The roll worker adds a bounded child process, and the generic factory still needs OS-enforced isolation and enforced per-mission aggregate resource spending before it can accept broader worker code.

Use a disposable development database. Stop with the CLI kill switch or discontinue the draft checkout. There are no runtime installation or service steps to reverse. Cancelled, expired and completed organizations cannot create more assignments. Save a copy of the database and exported evidence before discarding those development artifacts.

The Dog search produced no candidate for transfer. A future physical review would require a qualified read-only recording setup, calibrated time and coordinate alignment, observed limb and body pose, and repeatable paired simulations. Begin validation by comparing passive stationary recordings with a matching simulated stance. Plan any later active checks only after a candidate qualifies in simulation and a separate operator-approved qualification defines the start state, independent stop authority, physical exclusions, abort conditions and recovery path. None of the current estimates support physical motion.
