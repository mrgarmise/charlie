# Architecture, role contracts and acceptance

The Discovery notebook supplies the eligible question and owns the session, final claim statuses, follow-up edges and operator text digest. The opt-in development Learning Executive invokes Agent Factory ranking and commission. Agent Factory owns the sealed capability registry, agenda dependencies, leases, attempts, aggregate work limit and result fences. Its existing development scheduler and StimulusBus publish lifecycle transitions. The EvidenceJournal receives a terminal execution receipt. Discovery holds the research record, with source excerpts and their provenance. The sandbox ledger is the operational checkpoint during interrupted work.

| Role | Trusted inputs | Output |
| --- | --- | --- |
| Inventor | LE goal and supervisor invitation | Conditional proposal and prior-art search request |
| Archivist | Inventor proposal or retrieved evidence | Scope and novelty limitations, or distinct source-origin count |
| Scientist | Proposal and archive search agenda | Conditional arithmetic receipt or inconclusive finding, before evidence retrieval |
| Researcher | Scientist completion, query and trusted scope | Bounded untrusted excerpts and source provenance |
| Implementer | References and derivation | Proposed applications, practical alternatives and conditions |
| Independent evaluator | Derivation, imported rows and feasibility | Deterministic scope check, exact comparison, conflicts and organization score |
| Supervisor and final brief | LE scope; final evaluated evidence | Allowlisted assignments, stop reason and next question |

Typed result digests link dependencies. Sources are inert UTF-8 data. Trusted workers only use bounded SQLite retrieval and exact rational computations. A repeat on a known question can change the organization from broad search to scoped lookup and adds a second Archivist pass. An unrecognized question gets conservative offline retrieval and a validated arithmetic check if available. Role identities and permissions are supplied by code. Roles cannot open sockets, execute code, change approvals or issue commands through their result schema.

The additive `CollaborativeResearch/v1` record uses Discovery schema 2 and its append-only commit event. It preserves excerpt hashes separately from whole-row hashes, receipt digests, known upstream source metadata, scoped comparison results and follow-up IDs. Old notebooks remain readable. A journal commit uses the existing transaction and is replayed idempotently. The Factory attempt ledger covers interruption before the final commit and applies the precharged aggregate work budget. A generated record can establish conditional agreement with a reference under the declared assumptions. Shared assumptions and two rows from one publication do not constitute independent empirical replication.

The release assumes a private owner-operated scratch directory. It uses 12 precharged work units, an existing 120-second factory deadline, 30-second result leases and at most 14 scheduled turns per invocation. The CLI audits archive bytes and binds its manifest to the directory. It declines a second in-progress joint session in one sandbox. The implementation limits source excerpts and record size and caps admission when either development SQLite ledger reaches 16 MiB. The existing Discovery notebook and archive enforce their own bounds.
