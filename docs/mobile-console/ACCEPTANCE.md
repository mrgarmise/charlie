operator trial prerequisites. Keep all original failed/ambiguous records unchanged.

## Preparation

1. Record exact tested commit/tree, runtime hash, current worktrees/dirty files,
   startup configuration/PIDs, installed firmware/bridge/readback identity,
   camera/serial/network owners and protected existing learning/evidence paths.
2. Review the existing chassis qualification stages with the operator: positive
   hardware-local timed expiry, explicit STOP, network loss, Pi loss, independent
   physical cutoff, wheels-up bounds, floor braking and preemption. Retain at least
   the original required trial counts and all failures. Browser tests cannot
   qualify these stages.
3. Confirm an independently observed current camera-pan measurement and exposure
   age bound, authenticated exact-frame safety feed, direction-specific clearance,
   animal/human/floor/blind-spot controls and current inspected zone. MJPEG receipt
   age and N24 chassis yaw do not establish either missing measurement.
4. Confirm no unresolved durable uncertainty marker. Never remove it to arm the
   robot; use the established independent incident/requalification process.
5. Supply only genuine externally evaluated qualification and boot/device/zone-
   bound supervised authority through existing CapabilityDeployment interfaces.
   The console does not create grants, evidence booleans or firmware identities.
   Restart/runtime changes invalidate prior grants. Keep drive token absent until
   all readiness checks pass and the operator is present with the cutoff.

## Stationary read-only qualification

- Attach the console and a second face/evidence subscriber to the same existing
  feeder. Count physical opens/lease owners and record both consumer frame IDs.
  Close/reopen the web page; the other subscriber and feeder must continue.
- Record ten minutes of source identity/generation/sequence, unique displayed FPS,
  subscription FPS/drops, PNG encoding time, HTTP/decode distribution and receipt
  age. Report geometry/network/client hardware, CPU/RSS/temperature and sample
  counts. Exposure latency remains unknown unless a separately qualified optical/
  timestamp method supplies a measured bound. Do not label HTTP RTT as exposure
  latency. Compare the unmodified baseline before any transport/encoding change.
- Interrupt/recover the camera transport using the owner’s existing recovery path.
  Record stale display time, no-frame intervals and generation changes. Verify
  old boxes never appear on a new source/generation/frame/geometry.
- Independently authorize the existing read-only telemetry protocol, then compare
  ultrasonic readings against recorded physical references. Record centimeters,
  actual polling frequency, age, invalid measurements, faults and two independent
  subscribers. Source outage must remove current values. Yaw remains chassis yaw;
  optional unverified sensors remain deferred, not synthetic zeroes.
- Run existing hash-bound recognition through its normal source subscription.
  Record model identity, source/frame/generation, class/confidence/tracking ID,
  matched display frames, stale-result clearing and retained original evidence.
  Preserve Executive decisions, pet hypotheses and face behavior unchanged.

## Supervised motion qualification

After preparation passes, begin with the independently reviewed wheels-up setup.
The human owns the physical cutoff and witnesses actual wheel behavior. Bounded
software/ACK timing is separate from observed stopping and displacement.

- Confirm monitoring credential cannot acquire/drive; drive credential plus a
  current boot-bound lease can request only independently qualified directions,
  duration/PWM and environment. A competing operator cannot acquire. Preserve
  every rejected/unqualified request receipt.
- Hold/release each key and touch direction, including pointer cancel. Record
  event-to-wire and independently observed physical stopping, uncertainty and
  travel. Repeat focus loss, page hidden/navigation, browser closure, network
  interruption, stalled client/server and Pi loss using the existing reviewed
  loss/cutoff protocol. Do not kill a process without the operator controlling the
  independently qualified cutoff.
- Trigger emergency STOP during a request/slow camera encode/inference and while
  another client is monitoring. Verify immediate independent STOP admission,
  native latency bounds, physical stopping and persistent uncertainty/restart
  denial. A new browser/lease must not clear emergency state.
- Demonstrate manual acquisition preempts an in-flight autonomous face/pet pulse.
  Attempt competing face/pet dispatch and telemetry during manual ownership;
  motion must serialize through the same executor/transport, not queue commands.
  Release control and check intentional safe autonomous resumption separately.
- Forward and reverse need their own three direction-specific envelope/braking
  trials and measured evidence at the admitted max PWM/duration. Combined steering
  is successive separately admitted pivot/travel pulses. Do not qualify an
  invented wheel-mix protocol from a keyboard test.
- Floor travel follows only after the original direction-specific braking,
  coverage, preemption, local-expiry/loss and environmental checks pass. Obtain
  operator presence for that stage. Stop on unknown freshness/pose/cutoff,
  unexpected movement, thermal faults, failed/ambiguous STOP or a stale grant.
