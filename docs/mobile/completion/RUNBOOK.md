## Native safety producer and immutable proof contract

The actual installed sensor configuration is unavailable here, so this mission does **not** invent an ultrasonic FOV, pet-range association, floor/lateral coverage, exposure clock or sensor service. Before dispatch, bind a native sensor producer to the installed verified hardware and qualify its source hash. This is the exact remaining native integration dependency. Bind it to the current frame/track inside the existing acquisition path; do not replay a previous-frame file or infer current association from the scalar range. Supply verified pose to the existing tracker before associating across viewpoint changes, and require fresh confirmation if correspondence is uncertain. The snapshot contract by itself is not an installed native producer. A single ultrasonic return cannot populate every field. Relative FastDepth is not metric range, floor/stair clearance or proof that a photo is a live animal.

The producer atomically writes a bounded JSON safety feed (`charlie.mobile.safety-snapshot.v1`) containing boot_id, hardware_id, zone, frame_id, frame_sha256, track_id, firmware_sha256, producer_sha256, at (same Pi monotonic clock), pan_deg, yaw_deg, scene, capture_timing_verified, capture_age_seconds and sensors. Scene is `proxy-grounded` for supervised proxy authority or `live-animal-grounded` for live/operation authority. Both positive grounding and capture timing need independent measurement.

Sensors include separately sourced ultrasonic and target_range (meters, matching frame, verified FOV, selected track association for target_range); yaw degrees; heartbeat; floor_clearance, hazard_map, blind_spot and lateral_clearance (clear). Each has valid=true, source=car-qualified, at. pet_distress=false, pet_willing=true, human_clear=true, zone_inspected=true, power_ok=true are mandatory fresh supervisory/safety conditions, not classifier conclusions. Unknown values stay unknown and veto motion. Frame receipt <=500ms, sensor/feed <=250ms and proposal <=100ms are engineering maxima, not physical certifications. Any feed change during a pulse stops it; new motion needs fresh observation/binding. Camera must be centered, pose consistent, and existing body owns steering. Off-axis camera handoff is reported and stopped; no blind legacy alignment is invoked.
