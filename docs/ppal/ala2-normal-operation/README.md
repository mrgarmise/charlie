## Permanent integration

* Finalized Robotron `report.json` is published atomically. The ordinary evidence roots are polled through existing acquisition/import interfaces. Hash-bound imports and relocated byte-identical frames reuse existing evidence identities.
* The Executive commissions the existing predictive meditation algorithm from original `tracks.json`, preserving iteration checkpoints and immutable machine-consumable results. Missing tracks produce an unavailable result, never invented experience. Context aliases recovered from another notebook do not commission a second meditation of the same source episode.
* Existing Reflection originates temporal hypotheses and alternatives. The existing portfolio, Evaluator/MemoryGateway and chooser commit bounded investigations. Rejected/unresolved findings and contradictions survive restart.
* Independent acquisition owners may deliver the existing `independent_motion_corpus` JSON schema to `STATE/acquisition-inbox/*.json`. Hash-bound qualification is required; model/replay labels cannot qualify it. Changed evidence can create a versioned continuation of a blocked question. Malformed deliveries are retained as rejected and do not grant authority.
* Eligible temporal candidates automatically reach the existing shadow/deployment gates under external offline authority. Subsequent validation streams execute through the **existing Forebrain/Hindbrain**, measuring candidate and baseline decisions and motion error. These are reused validation diagnostics, not fresh final evidence or physical games. Outcomes return durably to the Executive and MemoryGateway; failed subsequent diagnostics roll back offline activation.
* Crash recovery reconciles committed outcomes, deployment and feedback without rerunning sealed final evaluation. Explicit rollback revokes a proposal. Notebook locks exclude competing writers; source/artifact changes fail closed.

The finite rule-based Reflection vocabulary is not general intelligence, learned strategic reasoning or a manually supplied winning strategy. Only temporal estimation is eligible for the automatic offline planning adapter in this release. Existing semantic/model investigation interfaces remain available when their evidence and optional training dependencies are present; no physical policy adapter is added.
