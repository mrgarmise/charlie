# Bounded incident originals and independent reconciliation

Continues published sampling checkpoint 13f6595c3970b4eaf8c7ee78e287469ca6329146. All execution is host software fixtures/replay; no physical controls, native camera or qualified physical score. Prior original histories and failure reports are untouched.

CaptureEvidence now supports opt-in --rolling-seconds (default 0), --rolling-frames (60), --rolling-memory-mib (32). Zero duration means no rolling snapshot allocation. Defaults are diagnostic bounds, not Pi recommendations. Duration <=10s, count <=300, bytes independently enforced; a frame larger than rolling bytes is not copied into rolling memory. Exposure-age eviction runs even for oversized frames. Telemetry adds rolling/current/peak bytes and evictions alongside writer queue/encoding/emergency buffers. Existing bounded legacy diagnostic buffers are separately reported; sampled mode no longer collects duplicate per-frame cropped raw/annotated diagnostics. Remaining score/review buffers are independent disclosed instrumentation, not the required original sample stream.

request_incident(reason,preceding,following,prediction_id) records actual trigger/source/prediction IDs, requested interval and available originals before scheduling bounded past/future retention. Four active requests and 128 admitted session requests bound admission; each active request accounts up to 300 sources. Incident payloads reserve more queue capacity for predictable baseline and critical records. Overlap shares the original capture identity. Every request resolves durably with selected IDs and explicit unavailable/evicted/interrupted/budget shortfalls; selected IDs are not claimed durable until receipt verification. Completion rejects unresolved requests, duplicate source captures and out-of-interval incident originals. PPAL can request the interval after its own eligible tactical prediction contradiction. Requests select diagnostic evidence; they cannot replace the fixed independent sample dataset or authorize controls.

Existing MemoryEvaluator.reconcile_perception is offline. It validates original hashes and source identity; corroboration requires exact original timestamp, observation ID, geometry hash, independent identity association, declared positional uncertainty, and a hash-bound independent measurement-method qualification. No arbitrary method-reference string suffices. Consistent independent measurements corroborate within their declared combined error bound; contradictions dispute; conflicting/occluded/missing-qualified measurements remain unresolved. Finite normalized internal detections without saved pixels are merely plausible_but_not_independently_observed. Alternative explanations survive and no nearest image is used as a causal stand-in. This is conservative point/source reconciliation, not a claim that interpolation certifies a full trajectory. Multi-frame causal IDs remain in the original trace; future independently measured trajectory constraints remain an evidence prerequisite.

The normal acquisition path writes reconciliation only to its derived journal, retains original witness IDs, adds counts/findings/questions to the existing context, and resumes through the existing Executive/Reflection. Normal between-game processing invokes the same Evaluator and existing Reflection queues the discrepancies. It does not add another learning agenda. Repeat import preserves context/finding identities and all original bytes. New qualified independent inspection delivery remains through existing evidence-acquisition interfaces; these fixtures are not independent physical measurements.
