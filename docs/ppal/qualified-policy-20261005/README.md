## Actual paths and existing connections

`play_robotron.main`: `PiCameraSource`/calibrated frame -> detector and taught
recognizer -> `VisualAgency.observe` generic tracker associations and causal SELF
ownership -> `PersistentSelfTracker` recovery -> `_objects` persistent IDs ->
`WorldState` -> `Forebrain.update` -> `Hindbrain.decide` -> `Action` -> existing
`ArcadeController.execute`/TCP transport -> next captured observation/agency
response. `GameDiary`, steps, report and HUD/score evidence retain outcomes;
episode finalization/acquisition returns completed experience to development.
Uncertain identity/recovery already neutralizes controls outside ordinary play.
Calibration and START/session guards remain unchanged.

`closed_loop.EpisodeRunner`: source pixels -> `VisionPipeline.process` ->
`ObjectTracker.update` -> same Forebrain/Hindbrain -> configured sink -> next
frame -> HUD `RewardTracker`, optional causal simulator result -> durable log.
Absent unambiguous player produces a neutral action. This is also the existing
synthetic normal entry point used for offline runtime/restart acceptance.

Existing learned-shot influence is in Hindbrain's route-blocker decision:
`ShotModel.likely_hit` can change STAY to advance while firing, subject to next-step
collision checks. `EpisodeRunner` can load/update it through the existing shot
adaptation path. The current `play_robotron` entry point does not load that
synthetic shot model; no unsupported physical shot capability is inferred.

Existing qualified semantic models load before the episode. `SemanticObserver`
uses a bounded, drop-old worker and applies only admissible tentative labels to
unknown, active, unambiguous tracks; current taught labels and SELF outrank them.
This changes WorldState roles and therefore ordinary choices. That completed
interface/portable runtime, deployment authority, readiness and rollback are
preserved. Semantic prose/journals are never per-frame inputs.

Existing motion candidates originate in Reflection's preserved-meditation
question, are generated by the committed chooser plan, independently measured
on qualified trajectories, shadowed and activated by CapabilityDeployment.
They previously reached only `PlanningCandidate` and offline operational
feedback. Live constant-velocity projection remains a diagnostic shadow;
`shadow_action` is never the controller action. Forebrain previously retained
nearest rescue or survive, without a strategic-policy input.

## Added boundary and arbitration

`CapabilityDeployment.export_policy` freezes a `ppal-policy-v1` local JSON
artifact from a current authorized activation. It binds candidate, original
committed investigation/prediction, source evidence, independent evaluation,
permitted domains/specification, explicit offline authority, activation/rollback
identity, qualification, code revision/dirty flag, runtime source hashes and
integrity hash. Complete-game utility remains UNKNOWN. Evaluation, shadow,
supported resolution and original Reflection lineage are checked before export.
The loader verifies these against the read-only notebook at episode startup,
then closes it. Legacy activations lacking runtime qualification stay retained
and cannot silently acquire the new interface.

The compiled policy supplies a finite parameter/prediction vocabulary to the
existing Forebrain/Hindbrain, not another planner. Goal preference and initial
target threat-cost can inform Forebrain; existing rescue persistence is retained.
Position preference only resolves equally clear open-space alternatives. Firing
deadband can influence ordinary route clearing; it cannot alter emergency fire.
Motion prediction can inform a destination using the same observed physical ID.
These are domain interfaces, not claims that any value is a winning strategy.
No authentic strategy proposal or evaluator is fabricated by this implementation.

Current player/threat geometry stays authoritative. Immediate threat clearing/
evasion runs before strategic/tactical policy influence. Motion never replaces
observed player, threats, semantic roles or identity with predicted state.
Unsafe observation produces neutral; unresolved occupied next steps prohibit
learned movement. The shot model remains independent and compatible. Predictions
are reset on reacquisition; non-increasing capture timestamps cannot advance them.

The older full-projected-world motion diagnostic remains available and its
published outcomes are preserved. Normal developmental feedback now separately
records the qualified runtime policy action/provenance alongside that diagnostic;
the two are not conflated. It exports the eligible version durably before use.

No meditation, Executive, candidate training, network call, journal scan or
evaluation is performed by Forebrain/Hindbrain decisions. Startup compilation
and journal verification are outside timing. The existing player consumes
`--learned-policy`, or discovers `CHARLIE_LEARNING_STATE/ppal-policy.json` before
an episode. The existing synthetic `run_closed_loop` consumes `--learned-policy`.
Baseline entry points require no policy. Invalid/unqualified/stale/revoked files
fail closed. Physical decision-policy loading is deliberately rejected: an arm
flag and offline activation cannot confer physical policy authority.

Goal reasoning and Hindbrain action reasoning retain compact durable policy,
candidate, investigation, evaluation and activation IDs plus applied domains.
Existing logs retain observed state, goal, intent, action and next outcome for
later reconstruction; lookup is outside gameplay. The player logs full chooser
duration; benchmark reports include both Forebrain and Hindbrain/provenance.
