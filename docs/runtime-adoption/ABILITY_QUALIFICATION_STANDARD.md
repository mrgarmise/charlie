# Ability qualification standard

Every ability has its own admission record. Source inclusion, software tests,
native observation, master approval, release approval, installation, enablement
and measured benefit are independent states. A stationary display does not need
a motion trial; mark motion NOT APPLICABLE. Manual consultation approved in the
existing runtime does not approve the candidate's autonomous consultation.

1. Pin source SHA/tree, donor slice, installed firmware/readback, model/dataset,
   calibration, runtime/boot/zone, source timestamps and evidence hashes. Classify
   resource owners, privacy, storage and physical hazards. Identify a rollback.
2. Verify dependency closure, default-off admission and compatibility with the
   actual local approval hierarchy. Preserve original adverse evidence and sealed
   labels. An ACK proves protocol handling, never physical response or pose.
3. Run focused, canonical ownership/STOP, negative authority, state durability,
   kill/restart and rollback tests, then full tests and applicable browser,
   firmware build and optional CPU engineering jobs on the exact independent CI
   head. Retain failures, skips, artifact digests and repaired results.
4. Obtain authorization for N0 identity discovery, then N1 disarmed stationary
   observation. Measure authentic exposure FPS, age/latency distributions,
   missing/replayed frames, CPU/RSS/temperature, resource contention and cleanup.
   Use the existing ability contract's quantitative limits; do not invent a new
   physical cutoff from an ACK or a host benchmark.
5. N2 verifies authenticated interfaces, audience/retention, one Executive/journal,
   no migration, restart recovery and independent owners. Approved manual Qwen
   retains its existing bounded resource/context/time/cleanup guards. Native
   autonomous meditation additionally requires the existing <=90-second slot,
   cooldown/rate policy, real RP2040 ACK/TTL, emergency precedence, root ownership
   and a genuinely eligible authentic question. Held questions stay held.
6. Only where applicable and separately authorized, N3 uses independent physical
   cutoff and supervised wheels-up tests: STOP, expiry, network/Pi loss, stale
   exposure, preemption, floor/sensor geometry and measured braking/travel. N4
   tests bounded zone-specific behavior, willing operator intervention and
   revocation. Cat interaction requires successful proxy trials first.
7. An independent reviewer signs the exact evidence-bound ability/stage record.
   Stage disabled, qualify admission, approve cutover separately, then perform N5
   observation and measure ability-specific benefit. Unknown results revoke that
   ability without invalidating unrelated accepted stationary observations.

Requalify affected contracts after code, firmware, model, calibration, hardware,
boot/owner, audience, environment or safety-limit change; expire stale evidence.
Retire by denying new admission, completing safe cleanup, preserving evidence and
restoring the approved version using the actual operator rollback procedure.
