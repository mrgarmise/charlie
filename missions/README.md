# Charlie mission archive (staging)

This branch is a staging area for a curated archive of Charlie development mission instructions originating from ChatGPT Library.

**Privacy note:** `mrgarmise/charlie` is a **public repository**; this branch and all its contents are publicly readable. No Library mission documents have been uploaded yet. Review for credentials, confidential data, or sensitive operational details before adding files.

Planned structure:

- `missions/active/` — currently approved implementation instructions
- `missions/archive/` — historic missions and handoffs
- `missions/INDEX.md` — filenames, original Library paths, deduplication and status

Do not modify runtime, deploy firmware, or merge a PR based on mission documents alone. The original Library files remain unchanged.
