# Preregistered offline comparison
Freeze before generating data. Fit one integer latency (0–4 control ticks) on isolated pulses. Reserve sinusoid and reversal families for validation. Fixed baseline is zero delay. Use the same observations for a uniformly sampled one-candidate comparator. Use per-trajectory RMS pixel distance, fraction of visible frames recovered and conditional 95% intervals resampled by trajectory. Ground truth is evaluator-only. Require separation on training and strict improvement on each held-out family. Reject stationary, low-visibility or inconsistent evidence. Physical eligibility always false. For skill practice stop at existing simulator termination or mechanical limit, and reject any failed rollout. Report missing native measurements explicitly.
